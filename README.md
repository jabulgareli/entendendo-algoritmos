# Projetos de Algoritmos - "Entendendo Algoritmos"

Este repositório contém implementações práticas dos algoritmos descritos no livro **"Entendendo Algoritmos"** de Aditya Bhargava. Cada algoritmo será implementado como um projeto independente, com explicações e exemplos para facilitar o entendimento. Todos na linguagem de programação c#.

## Algoritmos Implementados

- [Binary Search](src/BinarySearch) - Busca Binária.
- [Quick Sort](src/QuickSort) - Algoritmo de Ordenação Rápida.
- Mais algoritmos em breve!

## Estrutura do Repositório

Cada pasta neste repositório representa um algoritmo e contém:

- Código-fonte do algoritmo.
- Testes (quando aplicável).
- Explicação breve do funcionamento e exemplos.

## Livro: "Entendendo Algoritmos"

Este repositório é baseado no livro **"Entendendo Algoritmos"**. É um excelente recurso para aprender os conceitos fundamentais de algoritmos e estruturas de dados.

## Como Contribuir

Sinta-se à vontade para contribuir com este repositório. Sugestões de melhorias ou implementações de novos algoritmos são sempre bem-vindas!

1. Faça um fork do repositório.
2. Crie um branch para sua feature (`git checkout -b feature/nome-feature`).
3. Realize as alterações e faça commit (`git commit -m "Descrição das alterações"`).
4. Envie o push para o branch (`git push origin feature/nome-feature`).
5. Abra um Pull Request.
